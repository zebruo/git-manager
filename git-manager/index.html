Interface git-manager

Installation

Au préalable

Git doit être installé sur le serveur avant d'utiliser Git Manager. Vérifiez avec git --version dans un terminal. Sur Windows, Git Manager est compatible avec Git for Windows.

  1. Créez un dossier racine pour vos projets Git, par exemple C:/repos/.
  2. Copiez le dossier git-manager/ dans ce dossier racine.
    Si le dossier extrait porte un numéro de version (ex : git-manager-1.3.0/), renommez-le en git-manager/.
  3. Créez un virtual host Apache pointant vers C:/repos/.
  4. Renommez git-manager/git-config.example.php en git-manager/git-config.php et renseignez vos informations.
  5. Ouvrez http://votre-vhost.local/git-manager/ dans le navigateur.

N'ouvrez pas les fichiers via l'Explorateur Windows (file://) — PHP doit être exécuté par Apache.

<?php
return [
    // Identité Git pour les commits
    'userName'  => 'votre-username',
    'userEmail' => 'votre-email@example.com',

    // Clé SSH pour l'authentification GitHub (facultatif)
    // Clé RSA : C:/Users/votre-nom/.ssh/id_rsa
    // Clé ED25519 : C:/Users/votre-nom/.ssh/id_ed25519
    'sshKeyPath' => 'C:/Users/votre-nom/.ssh/id_rsa',

    // Dossier racine contenant vos projets Git
    'reposRoot'  => 'C:/repos',

    // Options d'affichage (facultatif)
    'options' => [
        'maxHistoryItems' => 20,
        'maxFileLogItems' => 10,
    ]
];

git-config.php contient vos données personnelles et ne doit pas être versionné. Il est automatiquement ignoré par .gitignore.

Voir aussi la page authentification Token/SSH.

Structure recommandée

C:/repos/ <- reposRoot + document root Apache ├── git-manager/ <- L'application (pas de .git/ → ignoré du sélecteur) │ ├── api/ │ ├── css/ │ ├── js/ │ ├── git-api.php │ ├── git-config.php <- Votre configuration (à créer) │ ├── git-config.example.php <- Modèle de configuration │ ├── git-manager.html │ ├── git-clone.html │ ├── git-help.html │ ├── git-auth.html │ ├── git-reset-remote.html │ ├── index.html │ └── flavicon.svg ├── project-a/ <- Affiché dans le sélecteur │ └── .git/ ├── project-b/ <- Affiché dans le sélecteur │ └── .git/ └── project-c/ <- Affiché dans le sélecteur └── .git/
  • Seuls les sous-dossiers directs de reposRoot contenant un .git/ sont listés dans le sélecteur.
  • Un seul virtual host suffit pour gérer tous vos dépôts.
  • Pour cloner ou créer un dépôt : bouton Clone dans git-manager.
  • Sécurité : chaque chemin est validé avec realpath() pour éviter toute traversée de répertoire.

Cas d'utilisation

Nouveau projet

Clonez un dépôt existant ou créez un dépôt vierge depuis l'interface.

Branches

Créez, basculez et fusionnez vos branches. Gérez les rebases avec les boutons Continuer / Abandonner.

Historique & Récupération

Parcourez vos commits, consultez l'historique par fichier et restaurez une version précise.

Tags & Releases

Créez des tags annotés et publiez des releases directement sur GitHub.

Stash

Mettez de côté vos modifications en cours sans commiter et reprenez-les quand vous voulez.

Synchronisation

Push, pull et fetch pour synchroniser avec GitHub ou GitLab.
