Interface git-manager

Installation

Au préalable

  1. Copiez le dossier git-manager/ à la racine de votre projet.
  2. Renommez git-config.example.php en git-config.phpet renseignez vos informations dans git-config.php :
  3. Token dans l'URL (https://TOKEN@github.com/user/repo.git) : fonctionne sans git-config.phpcar l'authentification est dans l'URL du remote elle-même.
  4. Credential Manager (git config --global credential.helper store ou wincred) : fonctionne sans git-config.phpcar les identifiants sont stockés au niveau global de Git.
  5. Le git-config.phpest vraiment indispensable pour le SSH (qui ne fonctionnera pas si sshKeyPathest vide, le processus PHP ne trouvera pas les clés).

Voir aussi la page authentification Token/SSH dans l'interface git-manager.

<?php
return [
    // Identité Git pour les commits
    'userName' => 'votre-username',
    'userEmail' => 'votre-email@example.com',

    // Clé SSH pour l'authentification GitHub (facultatif)
    // Clé RSA : C:/Users/votre-nom/.ssh/id_rsa
    // Clé ED25519 : C:/Users/votre-nom/.ssh/id_ed25519
    'sshKeyPath' => 'C:/Users/votre-nom/.ssh/id_rsa',

    // Options d'affichage (facultatif)
    'options' => [
        'maxHistoryItems' => 20,      // Nombre de commits dans l'historique
        'maxFileLogItems' => 10,      // Nombre de commits par fichier
    ]
];

Note : git-config.php contient vos données personnelles et ne doit pas être versionné. Il est automatiquement ajouté au .gitignore.

Via Git Manager

Lancez l'interface (en bas de page) — Rappel : Le dossier git-manager/ doit être copié dans le répertoire du projet :

  • Lancez git init depuis l'interface git-manager
  • Le .gitignore est automatiquement créé avec git-manager/
  • Renommez git-config.example.php en git-config.php et renseignez vos informations

Clone — Git Manager s'occupe de tout :

  • Les fichiers de l'application sont automatiquement copiés dans le dossier git-manager/ du nouveau projet
  • Le .gitignore est complété avec git-manager/ pour que le dossier ne soit jamais versionné
  • Il ne reste plus qu'à renommer git-config.example.php en git-config.php et renseigner vos informations
