Mettre de côté (Stash)

Sauvegarde temporairement vos modifications en cours sans créer de commit.
Utile pour changer de branche rapidement ou tester quelque chose sur un code propre.
Utilisez Pop pour restaurer et supprimer le stash, ou Appliquer pour restaurer en le conservant, ou Supprimez définitivement le stash.

Récupérer un fichier

Restaure un fichier à une version précédente sans affecter les autres fichiers.
Sélectionnez le fichier, choisissez la source (commit précédent, distant...) puis cliquez sur Récupérer.
Annuler toutes les modifications remet tous les fichiers modifiés au dernier commit. Irréversible.

Supprimer un fichier du dépôt

Supprimer : supprime le fichier ou dossier du dépôt ET de votre disque.
Arrêter le suivi : retire le fichier ou dossier du dépôt mais le conserve localement.
Après l'action : sélectionnez le fichier ou dossier D, saisissez un message tel que chore: supprimer "nom du fichier ou dossier" du dépôt et faites Commit & Push.
Le fichier ou dossier réapparaîtra en U (normal : il existe encore sur votre disque). Ajoutez-le au .gitignore si vous ne voulez plus le voir.

Marque un commit précis (ex : une version de release).
Avec un message → tag annoté. Sans message → tag léger.

Quand faire une release ?
Quand le projet est dans un état stable et qu'un jalon significatif est atteint : nouvelle page fonctionnelle, fonctionnalité importante, refonte visuelle.
Ne pas créer une release pour chaque petit fix.

Schéma de version : MAJOR.MINOR.PATCH
 · PATCH (+0.0.1) : correction de bug ou petit ajustement
 · MINOR (+0.1.0) : nouvelle page ou fonctionnalité
 · MAJOR (+1.0.0) : refonte architecturale ou visuelle importante
