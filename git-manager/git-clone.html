Cloner un dépôt

Prérequis — Le dossier /git-manager doit déjà être en place sur un projet existant. Le dépôt est toujours cloné dans le dossier parent du projet actuel : …

Mode opératoire

  1. Créer un virtual host Apache pour le nouveau dépôt (avant le clonage).
  2. Cloner le dépôt ci-dessous.
  3. Renommer git-config.example.php en git-config.php et renseigner identité Git et chemin SSH.
  4. Accéder à http://[nom-du-projet]/git-manager/git-manager.html.
  5. Si ce dépôt est destiné à un nouveau projet : modifier ou supprimer le remote origin (il pointe encore vers le dépôt cloné).

Ouvrir le dossier via l'Explorateur Windows (file://) ne fonctionnera pas — PHP doit être exécuté par Apache.

Mode multi-dépôts — Le dépôt sera cloné dans : …

Les fichiers git-manager ne sont pas copiés — cette installation est partagée entre tous les dépôts.
