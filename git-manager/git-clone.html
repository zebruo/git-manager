Créer un dépôt vierge

Démarre un nouveau projet ou met sous Git un dossier existant. Tape le nom du dossier ci-dessous :

  • le dossier n'existe pas : il est créé, puis initialisé (git init) ;
  • le dossier existe sans dépôt Git : il est initialisé sur place, ses fichiers ne sont pas touchés ;
  • le dossier est déjà un dépôt Git : rien n'est modifié, un message d'erreur s'affiche.
Nouveau dossier : lettres, chiffres, points, tirets (-) et underscores (_) uniquement.
Dossier existant : tape son nom exact (mêmes caractères autorisés).
